# 📊 eCommerce Behavior Analysis: 가격 저항선 및 브랜드 전환율 연구

13GB 규모의 대규모 이커머스 로그 데이터를 활용하여, 소비자 심리에 근거한 가격 저항선을 탐색하고 브랜드 파워가 구매 결정에 미치는 영향을 분석한 프로젝트입니다.

## 📅 분석 데이터 정보
* **Source:** Kaggle eCommerce Behavior Data from multi-category store
* **Period:** 2019년 10월 ~ 2019년 11월 (Full Data)
* **Scale:** 약 13GB / 약 4,200만 건의 행(Rows)

## 🛠 핵심 기술 스택 및 엔지니어링
* **언어 및 라이브러리:** `Python`, `Pandas`, `Matplotlib`, `Seaborn`
* **대용량 데이터 처리:** * 단일 로컬 환경의 RAM 한계를 극복하기 위해 **Pandas Chunking(100만 행 단위 분할 처리)** 기법 적용.
  * 13GB 로우 데이터를 샘플링 없이 전수 조사하여 데이터의 통계적 신뢰도 확보.
* **데이터 전처리:** * 유저 세션 로그 내 비정상 데이터(Price=0) 제거.
  * 퍼널 구조 불균형(Purchase > Cart) 감지에 따른 분석 지표 보정 (조회 대비 구매율 중심).

## 📈 주요 분석 인사이트

### 1️⃣ 소비자 심리적 가격 저항선 ($300)
* 전수 분석 결과, **$300**을 기점으로 구매 전환율(CVR)이 50% 이상 급락하는 현상 발견.
* 특히 삼성 등 안드로이드 기반 스마트폰의 경우 $250-300 구간 대비 $300-350 구간의 성과가 현저히 낮게 나타남.

### 2️⃣ 브랜드 충성도에 의한 가격 저항 무력화 (Apple 구간)
* 일반적인 '고가격-저전환' 가설과 달리, **$950-1,000** 고가 구간에서 전체 최고 전환율인 **2.74%** 기록.
* 해당 구간 구매의 **90% 이상이 Apple 제품**으로 확인되었으며, 프리미엄 브랜드 파워가 소비자의 심리적 가격 벽을 상쇄함을 입증.

## 💡 비즈니스 제안
* **Pricing:** $300 장벽을 넘지 않는 **$299 전략**이 중저가 브랜드 매출 극대화에 필수적임.
* **Marketing:** $700 이상 고가 라인업에서는 가격 할인보다 브랜드 가치 제안 및 보상 판매 등 결제 문턱을 낮추는 전략 권장.
